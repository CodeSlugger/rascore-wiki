# Плотности

Ловит **крупные лимитные заявки** в стаканах **Aster** (от $100k) и **Binance Alpha** (от $50k) и
присылает алерт, когда цена подошла к ним ближе заданного процента (по умолчанию 5%).

## Что считается плотностью

- Уровень не меньше порога биржи.
- **Выделяется среди соседей**: в заданное число раз крупнее обычных крупных уровней рядом. Иначе
  таблицу забивали бы ровные «стенки» маркетмейкеров.
- **Стоит** не меньше заданного времени: мигающие заявки не в счёт.

Когда плотность исчезла: цена дошла до неё — «разъели», не дошла — «сняли».

Картинка — минутные свечи за час с уровнем плотности. Совет: уберите в чёрный список тяжи и токены
акций (BTC, ETH, SNDK…) — на них такие уровни стоят всегда.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Биржи | биржи | aster, binance_alpha |
| Плотность на Aster от, $ | число (от 1000 до 1000000000) | 100 000 |
| Плотность на Binance Alpha от, $ | число (от 1000 до 1000000000) | 50 000 |
| Алерт, когда цена ближе, % | число (от 0.1 до 10) | 5 |
| Крупнее соседних уровней, × (1 — не проверять) | число (от 1 до 100) | 3 |
| Стоит не меньше, сек | число (от 0 до 3600) | 30 |
| Алерт: цена подошла к плотности | вкл/выкл | вкл |
| Алерт: плотность разъели | вкл/выкл | вкл |
| Алерт: плотность сняли | вкл/выкл | выкл |
| Кулдаун на монету и сторону, мин | число (от 0 до 1440) | 10 |
| Строк в таблице | число (от 5 до 300) | 50 |
| Только монеты | список | пусто |
| Чёрный список | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | капля |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
