# Вход и доступ

## Через Telegram

1. На [rascore.site](https://rascore.site) нажмите **«Войти через Telegram»**.
2. Откроется бот rascore — нажмите **Start**.
3. Вернитесь на сайт: вход произойдёт сам.

Домен и HTTPS для этого не нужны, работает и в мобильном браузере.

## По почте

На странице входа укажите почту — придёт **шестизначный код**. Код живёт 10 минут, на ввод даётся
5 попыток, новый код можно запросить не чаще раза в минуту. Тем же способом сбрасывается пароль.

## Одобрение доступа

Новый аккаунт попадает в заявки. Пока администратор его не одобрил, виджеты не работают. Если доступ
отозвали, детекторы ваших виджетов останавливаются.

Без привязанного Telegram сайт показывает только окно входа.

## Сессия

Вход запоминается в браузере. Кнопка выхода — в правом верхнем углу.
