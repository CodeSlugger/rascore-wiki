# Настройки виджета

Шестерёнка **⚙ Настройки** в углу виджета открывает форму. Изменения применяются сразу, перезапускать
ничего не нужно. Полный список настроек каждого виджета — на его странице в разделе [Виджеты](../widgets).

## Общие настройки

Они есть у большинства виджетов.

| Настройка | Что делает |
|---|---|
| **Биржи** | На каких биржах искать. Для каждой можно оставить только фьючерсы или только спот. |
| **Рынки** | Фьючерсы, спот или оба. |
| **Чёрный список** | Монеты, которые виджет не смотрит. Пишутся без котировки: `BTC`, `ETH`, `1000PEPE`. Сюда убирают «тяжи» — крупные ликвидные монеты, по которым много шума. |
| **Только монеты** (белый список) | Если заполнен — виджет смотрит **только** эти монеты. |
| **Котируемые** | Пары с какими котировками брать (USDT, USDC…). Пусто — все. |
| **Кулдаун** | Сколько минут молчать по той же монете после алерта. |
| **Группы порогов** (тиры) | Свой порог для группы монет: например, BTC и ETH — от 0.3%, остальные — от 2%. |
| **Пороги по биржам** | Отдельная вкладка для каждой биржи со своими порогами: на Aster $10k — это вынос, а на Binance — шум. Куда слать, звук и терминал от биржи не зависят и на вкладках не показываются. |

## Доставка

| Настройка | Что делает |
|---|---|
| **Telegram** | Слать алерты этого виджета в Telegram. |
| **Ветка** | Номер ветки (темы) в вашей Telegram-группе — см. [Профиль](profile). |
| **Только в часы рынка США** | Есть у фондовых виджетов: в Telegram пишет только в сессию NYSE (и за час до неё), с учётом праздников. На сайте алерты идут всегда. |
| **Пуш Bark** | Присылать пуш на iPhone (ссылка Bark задаётся в профиле). |
| **Звук алерта** | Звук на сайте: капля, клик, звон, бип, двойной, низкий, восходящий или свой. |
| **Открывать в терминале** | При каждом алерте сразу открывать монету в Vataga, MetaScalp или Tiger.Trade. |

## Ограничения

- Не больше **30 алертов в минуту** с одного виджета, лишние не отправляются. Если упираетесь —
  поднимите пороги или уберите шумные монеты в чёрный список.
- Слишком низкие пороги подрезаются до разумного минимума. Например, у «Движений» минимум 0.5%: при
  0.05% один виджет давал сотни алертов в минуту.
