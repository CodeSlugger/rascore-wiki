# Алгос

Ловит алгоритм, который льёт **серию одинаковых по размеру принтов** в одну сторону и этим двигает цену.

## Когда полезен

Видно, что монету кто-то методично покупает или продаёт одинаковыми кусками, и куда он её ведёт.

## Как считает

- Сделки одного рыночного ордера склеиваются в один принт.
- Серия — от заданного числа принтов одной стороны с одинаковым размером, не меньше заданной суммы, с
  движением цены не меньше порога.
- ⏱ — принты идут ровным темпом, как метроном (алгоритм по таймеру).
- Отдельно помечается «алгос-урод»: принты, которые цену не двигают (льёт сам в себя).
- Когда серия заканчивается — алерт «алгос снялся».

## Алерт

Направление, размер принта, сколько их было, движение цены. В Telegram — секундный график с
отмеченными принтами. Кнопка «открыть в трекере».

Все прошлые включения алгосов и что цена делала потом — на странице [Статистика алгосов](../tools/stats).

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Мин. принтов в серии | число (от 2 до 50) | 3 |
| Девиация размера принта, % | число (от 0 до 50) | 5 |
| Мин. движение, % | число (от 0 до 50) | 2 |
| Окно поиска серии, сек | число (от 5 до 600) | 60 |
| Мин. размер принта, $ | число (от 0 до 10000000) | 2000 |
| Кулдаун, сек | число (от 0 до 3600) | 300 |
| Склейка сделок, мс | число (от 0 до 5000) | 100 |
| Урод: сдвиг на принт до, % | число (от 0 до 5) | 0.01 |
| Урод: биржи | список | binance_alpha, aster |
| Мин. доля ленты, % | число (от 0 до 100) | 30 |
| Помечать алгосов с таймингом | вкл/выкл | вкл |
| Тайминговый: мин. принтов | число (от 2 до 100) | 5 |
| Тайминговый: девиация, % | число (от 0 до 100) | 30 |
| Тайминговый: мин. интервал, мс | число (от 0 до 60000) | 300 |
| Тайминговый: мин. сдвиг, % | число (от 0 до 50) | 0.3 |
| Алго снялся: тишина, сек | число (от 0 до 3600) | 60 |
| Биржи | биржи | все |
| Котируемые | список | USDT, USDC |
| Чёрный список | список | USDC, FDUSD, TUSD, BUSD, DAI, USDE, USD1, USDP, EURI, XUSD,  |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Telegram только в часы рынка США | вкл/выкл | выкл |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | клик |
