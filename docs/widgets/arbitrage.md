# Арбитраж

Показывает **разницу цены одной монеты между биржами**: фьючерс-фьючерс, спот-фьючерс, спот-спот. В
расчёте — фандинг обеих ног (итог = спред + фандинг за сутки), объём и открыт ли ввод-вывод по сетям.

## Связка

Клик по строке открывает **окно связки** с посекундным графиком спреда. Оттуда можно поставить
**слежение** с границами «спред ≥ …» и «спред ≤ …» (например, «войду от 2%, выйду на 0.3%»). Оно работает
на сервере без открытого окна и присылает алерт в Telegram или Bark.

## Алерт

Обе ноги с фандингом и временем до него, другие маршруты, сети с открытым депозитом.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Открытая вкладка | выбор (all, fut-fut, spot-fut, spot-spot, in-venue) | fut-fut |
| Режимы во «Все» и алертах | выбор (fut-fut, spot-fut, spot-spot, in-venue) | fut-fut, spot-fut |
| Мин. спред, % | число (от -50 до 50) | 0 |
| Мин. объём 24ч, $ | число (от 0 до 1000000000) | 1 000 000 |
| Макс. спред стакана, % | число (от 0 до 50) | 0.5 |
| Строк в таблице | число (от 5 до 300) | 40 |
| Одна строка на монету | вкл/выкл | вкл |
| Сортировка | выбор (spread, net, funding24, volume) | spread |
| Биржи | биржи | все |
| Чёрный список | список | USDC, FDUSD, TUSD, BUSD, DAI, USDE, USD1, USDP, EURI, XUSD,  |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Telegram только в часы рынка США | вкл/выкл | выкл |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | звон |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
