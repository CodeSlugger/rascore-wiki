# Статус D/W

Ловит **момент, когда биржа закрыла или открыла ввод или вывод** монеты. Сам статус «выводы закрыты»
ничего не значит (у мелких монет так месяцами), важен **переход**, пока цены на биржах не разъехались.

Биржи: Gate, Bitget, KuCoin, Binance, Bybit, OKX. Ссылка в алерте ведёт на спот монеты на этой бирже.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Монеты | список | пусто |
| Опрос, сек | число (от 60 до 3600) | 300 |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | звон |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
