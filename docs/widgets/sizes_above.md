# Сайзы выше рынка

Ловит на неликвидных биржах (**Binance Alpha** и **Aster**) **лонг-лимитку, поставленную выше текущей
цены** — то есть через рынок. Такая лимитка сразу съедает аски до своей цены, а остаток встаёт бидом
над старой ценой. Этот бид обычно быстро съедают.

## Что считается сайзом

- В стакане появился новый бид **на цене не ниже прошлого лучшего аска** — иначе как через рынок его
  не поставить.
- Лимитка (съеденные аски + остаток бидом) — **от $10 000**.
- Её цена выше прошлой цены **на 0.2% и больше**.
- Остаток **в 3 раза крупнее соседних бидов**. Так отсекаются маркетмейкеры: когда они сдвигают всю
  лесенку вверх, их бид тоже встаёт на место старого аска, но он ровный, как соседние.

Лимитку, которая исполнилась целиком (остатка нет), от обычной покупки по рынку не отличить — такие не
ловим. Стакан проверяется раз в 2 секунды.

## Алерт

Приходит сразу, на каждую лимитку. В следующем алерте по той же монете видно, что стало с прошлой.

<div className="alert-sample">📈 САЙЗ ВЫШЕ РЫНКА{"\n"}Лонг-лимитка $199.3k на 0.0412 (+0.47% к цене){"\n"}Съела $109.7k асков (13 ур.) · остаток бидом $89.7k, ×22 к соседним{"\n"}Прошлая: $35.0k на 0.0405 — остаток съели · за час: 2</div>

Картинка — минутные свечи с линией лимитки. В таблице виджета — лимитки за последний час: сколько
съела, какой остаток и что с ним сейчас (**стоит / съели / сняли**).

## Совет

Если ловит мало — снизьте «Остаток крупнее соседних бидов» до ×2. Тяжи (BTC, ETH, SOL) лучше держать в
чёрном списке: там маркетмейкеры ставят сотни тысяч.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Биржи | биржи | aster, binance_alpha |
| Лимитка от (съела + остаток), $ | число (от 1000 до 1000000000) | 10 000 |
| Выше прошлой цены на, % от | число (от 0 до 50) | 0.2 |
| Остаток крупнее соседних бидов, × (1 — не проверять) | число (от 1 до 1000) | 3 |
| Строк в таблице | число (от 5 до 300) | 50 |
| Только монеты | список | пусто |
| Чёрный список | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | звон |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
