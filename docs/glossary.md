# Словарь

| Термин | Значение |
|---|---|
| **Принт** | Одна сделка в ленте (рыночный ордер). Шорт-принты — рыночные продажи, лонг-принты — покупки. |
| **Алгос** | Алгоритм, который льёт серию одинаковых принтов в одну сторону. |
| **Прострел (прокид)** | Резкое движение цены за секунду. В «Прострелах» — с возвратом цены назад, в «Раге» — ступенька вниз без возврата. |
| **Всос** | Какую часть прострела цена вернула назад. |
| **Разнолот** | Поток рыночных ордеров в одну сторону разными по размеру лотами. |
| **Залив** | Сильный односторонний поток (у многих так назван виджет «Разнолот»). |
| **Айсберг** | Алгоритм разгоняет цену до своей котировки и минутами сливает объём на этом уровне. |
| **Раг** | Слив монеты лесенкой прокидов вниз. |
| **Плотность** | Крупная лимитная заявка в стакане, заметно больше соседних. |
| **Разъели / сняли** | Плотность исчезла: цена дошла до неё и её съели / её убрали, пока цена была далеко. |
| **Спред** | Разница между лучшей ценой продажи и лучшей ценой покупки. |
| **Налив** | Рыночные продажи прямо в чью-то заявку на покупку (или наоборот). |
| **CVD** | Рыночные покупки минус рыночные продажи. Падает — продают рынком. |
| **OI** | Открытый интерес: сколько открыто позиций по фьючерсу. |
| **TWAP** | Ордер, который исполняется равными частями во времени. |
| **Фандинг** | Периодический платёж между лонгами и шортами на бессрочных фьючерсах. |
| **Депег** | Стейблкоин торгуется мимо своей привязки. |
| **D/W** | Ввод/вывод монеты на бирже (deposit/withdraw). |
| **Фонда** | Фондовый рынок США; «Фейр» — справедливая цена токена акции. |
| **Связка** | Пара бирж для арбитража одной монеты. |
| **Фреш** | Кошелёк, который ничего не отправлял и получил монету впервые. |
| **Раздача** | Монету почти одновременно получают много разных кошельков. |
| **Тяжи** | Крупные ликвидные монеты (BTC, ETH, токены акций). В большинстве виджетов их убирают в чёрный список. |
| **Тир, группа порогов** | Свой порог для группы монет внутри одного виджета. |
| **Кулдаун** | Сколько молчать по монете после алерта. |
| **Ветка** | Тема в Telegram-группе с темами. |
| **F / S** | Фьючерс / спот в шапке алерта. |
| **Тейкер / мейкер** | Кто бьёт рыночным ордером / чья лимитка стояла в стакане. |
