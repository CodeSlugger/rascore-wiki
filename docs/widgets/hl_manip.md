# Манипуляции HL

Ловит на Hyperliquid **кошельки, которые набирают позицию, а ликвидация у них близко к цене**. Так выглядела
манипуляция XPL: десятки кошельков держали лонги с ликвидациями кучкой у цены, а потом их по очереди выносили.

## Как работает

1. Бот слушает **все сделки Hyperliquid по всем монетам**. В каждой сделке видно, какой кошелёк купил, а
   какой продал.
2. По каждому кошельку и монете копится **чистый набор**: маркетмейкер то покупает, то продаёт, и у него
   набор около нуля, а набирающий копит в одну сторону. Старый набор постепенно забывается (половина — за 2
   часа).
3. Кошелёк набрал больше порога — бот смотрит его **позицию**: размер, плечо, вход и цену ликвидации.
4. Алерт приходит, когда на одной монете в одну сторону:
   - **кучка** — несколько кошельков (от 3), у каждого ликвидация не дальше 10% от цены, вместе от $500k;
   - **кит** — один кошелёк с позицией от 15% открытого интереса монеты и ликвидацией не дальше 10%.

```
🎯 XPL: 5 кошельков в ЛОНГ на $4.2M (12% OI) · ликвидации 0.0689–0.0712, до цены 3.1–6.4%
цена 0.0735 · медиана до ликвидации 4.6%
0x7132…a1b2 $1.3M x10 · ТВХ 0.0741 · ликв 0.0699 (4.9%)
…
```

Под алертом — ссылки на Hyperdash трёх крупнейших кошельков. Чтобы следить за ними дальше (и получать
предупреждения «до ликвидации меньше 5%… 1%»), добавьте их в [Трекер кошелька HL](./hl_wallet.md).

Позиции кошельков из кучки бот пересматривает раз в 5 минут: закрыли или вынесли — выпадают. Повтор по той же
монете и стороне — не раньше чем через час, или раньше, если сумма выросла в полтора раза.

Бот видит только тех, кто **набирал после его запуска**: позиция, открытая давно и без новых сделок, в
поле зрения не попадёт.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Кошелёк набрал по монете от, $ — смотрим его позицию | число (от 10000 до 100000000) | 100 000 |
| Позиция кошелька от, $ | число (от 1000 до 100000000) | 30 000 |
| До ликвидации не дальше, % | число (от 0.5 до 25) | 10 |
| Кучка: кошельков от | число (от 2 до 50) | 3 |
| Кучка: вместе от, $ | число (от 10000 до 1000000000) | 500 000 |
| Кит: позиция от, % открытого интереса монеты | число (от 1 до 100) | 15 |
| Кит: позиция от, $ | число (от 10000 до 1000000000) | 300 000 |
| Повтор по монете не раньше, мин | число (от 0 до 1440) | 60 |
| …или раньше, если сумма выросла во столько раз | число (от 1 до 10) | 1.5 |
| Чёрный список монет — о них не пишем (BTC, ETH) | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | звон |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
