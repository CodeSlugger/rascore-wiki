# Трекер

Рабочий стол **одной монеты**.

- **Биржевая монета**: живой график по сделкам, история свечей, стакан.
- **DEX-монета** (BSC/ETH): каждая сделка на пуле в реальном времени (задержка — один блок), продажи
  красным на секундном графике. Сутки истории подтягиваются сами. Пока поддерживаются пулы V2
  (PancakeSwap V2 и совместимые).
- **🔔 Алерт на цену**: поставьте уровень — придёт уведомление в Telegram или Bark, даже когда вкладка
  закрыта. Одноразовый; выше или ниже — определяется по текущей цене.
- Открывается из алертов «Алгоса» и «Разнолота» кнопкой «открыть в трекере».

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | клик |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
