# Открытый интерес

Ловит, когда **открытый интерес** по монете на бирже вырос или упал на N% за заданное окно.

## Как считает

- OI считается **в монетах**, а не в долларах: долларовый OI растёт от одной только цены.
- В алерте видно, **совпал ли** рост OI с движением цены. Набор по ходу движения и против него — это
  разные истории.
- История OI и кулдауны не сбрасываются при перезапуске сайта.

## Алерт

Текст и картинка с двумя рядами за окно — цена и OI, ссылка на CoinGlass. На сайте под графиком алерта
есть панель минутного OI.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Изменение OI от, % | число (от 0.1 до 500) | 30 |
| Окно, сек | число (от 60 до 86400) | 600 |
| Сторона | выбор (up, both, down) | up |
| Опрос, сек | число (от 30 до 600) | 60 |
| Мин. OI, $ | число (от 0 до 10000000000) | 1 000 000 |
| Мин. объём 24ч, $ | число (от 0 до 10000000000) | 1 000 000 |
| Кулдаун на монету, сек | число (от 0 до 86400) | 1800 |
| Биржи | биржи | все |
| Котируемые | список | USDT |
| Только монеты | список | пусто |
| Чёрный список | список | USDC, FDUSD, TUSD, BUSD, DAI, USDE, USD1, USDP, EURI, XUSD,  |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | низкий |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
