# Ликвидации акций

Ловит момент, когда **токен акции на Binance** (MINIMAX, POPMART, STXX и другие TradFi-контракты)
резко пролили **ликвидациями лонгов**, а не из-за новостей по самой акции. Если родная биржа акции в
этот момент **закрыта**, у цены нет якоря, и такой пролив обычно быстро откупают.

## Когда приходит алерт

Должно совпасть всё сразу:

- Токен — акция на Binance (их около 220: США, Гонконг, Корея, Китай, плюс сырьё и валюты).
- Цена упала **на 3% и больше** от максимума за последние **5 минут**.
- С момента этого максимума ликвидировано лонгов **от $10 000**.
- Ликвидации — **не меньше 10%** рыночных продаж за это время. Значит, пролив сделали именно
  ликвидации, а не обычные продавцы.
- Если включено «Только когда родной рынок закрыт», алерт придёт только вне торговой сессии акции.

Повтор по той же монете приходит через 30 минут или раньше, если она упала ещё на 3% («продолжается»).

:::note
Binance отдаёт не больше одной ликвидации в секунду на монету, поэтому сумма в алерте — **минимум**:
на самом деле ликвидировали больше.
:::

## Когда открыт родной рынок

- **США** — обычная сессия NYSE/Nasdaq с учётом праздников.
- **Гонконг** — 09:30–12:00 и 13:00–16:00 по Гонконгу (с обедом посередине).
- **Корея** — 09:00–15:30 по Сеулу.
- **Китай** — 09:30–11:30 и 13:00–15:00 по Шанхаю.
- В выходные все закрыты. Азиатские праздники пока не учитываются.

Картинка — секундные свечи пролива и минута до него.

## Таблица падений

В виджете вкладки **1ч / 4ч / 24ч** — какие акции упали за этот период, самые упавшие сверху (как
вкладка Stocks на Binance). В строке: тикер, родной рынок (🌙 — закрыт), график за период, цена,
изменение и сколько лонгов ликвидировано за период. Клик по строке открывает монету в терминале.
Вкладка **Алерты** — лента сработавших проливов.

Ликвидации в таблице копятся с момента запуска сервера: Binance не отдаёт их задним числом.

## Совет

Самые чистые сетапы — когда рынок закрыт (ночь США, выходные, обед в Гонконге). Если хотите только
их, включите «Только когда родной рынок закрыт».

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Падение от максимума окна, % от | число (от 0.5 до 50) | 3 |
| Окно, мин | число (от 1 до 60) | 5 |
| Ликвидировано лонгов от, $ | число (от 0 до 1000000000) | 10 000 |
| Ликвидации — не меньше доли продаж, % | число (от 0 до 100) | 10 |
| Только когда родной рынок акции закрыт | вкл/выкл | выкл |
| Кулдаун на монету, мин | число (от 0 до 1440) | 30 |
| Повтор раньше кулдауна, если упала ещё на, % | число (от 0 до 50) | 3 |
| Только монеты | список | пусто |
| Чёрный список | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | низкий |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
