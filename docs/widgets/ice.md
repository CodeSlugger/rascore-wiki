# Рыночные айсберги

Ловит алгоритм-«покупаш», который **разгоняет цену рыночными покупками до своей котировки, а потом
минутами сливает объём в этот же ценовой уровень**. На футпринте это столбик крупных красных кластеров
на одной цене. Зеркальный случай — откуп после пролива.

## Как считает

- Сделки раскладываются в кластеры **минута × уровень цены × сторона**, как на футпринте.
- Крупный кластер — от заданной суммы и в разы больше обычного кластера монеты.
- Алерт — крупные кластеры одной стороны **несколько минут подряд** на одной цене (или лесенкой).
- Перед этим должен быть **быстрый разгон** противоположной стороной.
- Тяжи не смотрит: на них крупные кластеры каждую минуту. По умолчанию — Aster.

График с отметками разгона; в Telegram — картинка футпринта с цифрами кластеров.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Кластер от, $ | число (от 0 до 100000000) | 20 000 |
| Кластер от, × к обычному | число (от 1 до 100) | 5 |
| Шаг кластера, % | число (от 0.01 до 5) | 0.1 |
| Минут подряд | число (от 1 до 30) | 2 |
| Лесенка, шагов за минуту | число (от 0 до 10) | 1 |
| Разгон к уровню от, % | число (от 0 до 50) | 0.5 |
| Разгон не дольше, сек | число (от 1 до 180) | 30 |
| Принт разгона от, $ | число (от 0 до 10000000) | 5000 |
| Кулдаун на монету, сек | число (от 0 до 7200) | 600 |
| Мин. объём 24ч, $ | число (от 0 до 10000000000) | 0 |
| Макс. объём 24ч, $ | число (от 0 до 100000000000) | 5 000 000 |
| Рынки | рынки | фьючерсы и спот |
| Биржи | биржи | aster |
| Котируемые | список | USDT, USDC |
| Чёрный список | список | USDC, FDUSD, TUSD, BUSD, DAI, USDE, USD1, USDP, EURI, XUSD,  |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Telegram только в часы рынка США | вкл/выкл | выкл |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | низкий |
