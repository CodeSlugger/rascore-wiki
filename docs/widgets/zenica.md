# Движения цены

Ловит, когда **цена прошла X% за N секунд** на любой включённой бирже, спот и фьючерсы.

## Когда полезен

Быстрые импульсы, выносы, листинги, пампы и проливы: в Telegram это первое, что надо увидеть.

## Как считает

- Проверяет каждую сделку, без ожидания закрытия свечи.
- Движение считается **от экстремума окна**: рост — от минимума, падение — от максимума.
- **Чистота движения** отсекает «качели» на неликвиде: если цена прыгает 100 → 102 → 100, это не движение.
- Одно движение — один алерт: кулдаун действует на монету целиком, по всем биржам сразу.
- **Группы порогов**: свой порог для своих монет (например, 0.5% для BTC и 3% для остальных).

## Алерт

<div className="alert-sample">🟢 BTCUSDT +3.14% BINANCE SPOT $1.5M MC $120M 1m 5s</div>

Движение, **объём монеты за сутки**, **капитализация** (считается по цене в момент алерта) и время,
за которое прошло движение. В Telegram всё, что сработало за одну секунду, приходит одним сообщением,
и **«Движения» уходят раньше любых других алертов**. Клик по алерту на сайте копирует тикер.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Движение, % | число (от 0.5 до 100) | 2 |
| Окно, сек | число (от 5 до 3600) | 60 |
| Направление | выбор (both, up, down) | both |
| Логика бота ZenAlerts | вкл/выкл | вкл |
| Мин. объём 24ч, $ | число (от 0 до 10000000000) | 1 000 000 |
| Чистота движения, % | число (от 0 до 100) | 40 |
| Кулдаун, сек | число (от 0 до 86400) | 60 |
| Мин. сделок в окне | число (от 1 до 1000) | 5 |
| Рынки | рынки | фьючерсы и спот |
| Биржи | биржи | все |
| Пороги по монетам | группы порогов | BTC, ETH — от 0.5% |
| Только монеты | список | пусто |
| Котируемые | список | USDT, USDC |
| Чёрный список | список | USDC, FDUSD, TUSD, BUSD, DAI, USDE, USD1, USDP, EURI, XUSD,  |
| Оборот 24ч в алерте | вкл/выкл | вкл |
| Префикс | текст |  |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Telegram только в часы рынка США | вкл/выкл | выкл |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | капля |
