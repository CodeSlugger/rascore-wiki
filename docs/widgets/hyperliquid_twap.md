# TWAP Hyperliquid

Показывает **нативные TWAP-ордера Hyperliquid**: кто, какая монета, сторона, размер, сколько исполнено,
статус. Только то, что подтвердила биржа, без угадывания по принтам.

## Что в алертах

- Новый TWAP, исполнение, завершение.
- **Импакт** 🟢🟡🔴 — как цена отреагировала в сторону TWAP за пару минут.
- **«TWAP похоже выключён»** — исполнение перестало расти дольше минуты.
- Новые события дописываются в **то же сообщение**, а не новым.
- Свой порог $/мин на монету: например `SOL=1м ETH=500к` (без пробелов вокруг `=`).

От блока до Telegram — около 5 секунд.

| Настройка | Что задаёт | По умолчанию |

| Свой порог $/мин по монетам: SOL=1м ETH=500к | список | пусто |
| Мин. остаток, $ | число (от 0 до 1000000000000.0) | 0 |
| Мин. длительность, мин | число (от 1 до 10080) | 5 |

| Направление | выбор (both, B, A) | both |
| Рынки Hyperliquid | выбор (all, perp, spot) | all |
| Рынки HIP-3 | вкл/выкл | вкл |
| Включать TWAP с reduce-only | вкл/выкл | вкл |
| Ждущие условия цены | вкл/выкл | выкл |
| Только монеты | список | пусто |
| Исключить монеты | список | пусто |
| Кошельки в ЧС — не присылать | список | пусто |
| Хорошие кошельки 👍 | список | пусто |
| Плохие кошельки 👎 | список | пусто |
| Завершённые, мин | число (от 0 до 1440) | 30 |
| Строк в таблице | число (от 10 до 500) | 100 |
| Сортировка | выбор (volume, newest, remaining, rate) | volume |
| Telegram | вкл/выкл | выкл |
| Ветка Telegram | число (от 0 до 10000000) | 0 |
| Пуш Bark | вкл/выкл | выкл |
