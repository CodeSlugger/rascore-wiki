# Переводы

Ловит **завоз монеты на свежий кошелёк**: так часто выглядит подготовка к раздаче или сливу.

## Что умеет

- **Фреш**: получатель раньше ничего не отправлял, и монета пришла к нему впервые. Видно, какая это доля
  капитализации монеты.
- **Слежка за фрешем**: ⛽ завезли газ (готовится) → 📉 баланс просел (начал продавать) → 🏁 вышел.
- **Раздача**: одну монету почти одновременно получили много разных кошельков.
- **Потоки бирж**: сколько монеты завели на биржи и вывели с них.
- **Карта потоков**: кто кому передавал монету вокруг кошелька, до источника и обратно.

## Алерт

Карточка: адреса ссылками на Arkham, сеть, капитализация, есть ли газ. Продажи, раздачи и минты можно
развести по своим веткам Telegram.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Переводы от, $ | число (от 0 до 10000000000) | 300 000 |
| Строк в таблице | число (от 5 до 500) | 50 |
| Занос от, $ | число (от 0 до 10000000000) | 300 000 |
| Только свежие кошельки | вкл/выкл | вкл |
| Чёрный список монет | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Ветка продаж | число (от 0 до 10000000) | 0 |
| Раздача: кошельков от | число (от 3 до 200) | 5 |
| Раздача: объём от, $ | число (от 0 до 1000000000) | 1 000 000 |
| Раздача: окно, мин | число (от 1 до 180) | 15 |
| Ветка «раздачи» | число (от 0 до 10000000) | 0 |
| Ветка «минты» | число (от 0 до 10000000) | 0 |
| Пуш о минтах: ссылки | список | пусто |
| Пуш: повторов | число (от 1 до 20) | 5 |
| Пуш: пауза, сек | число (от 1 до 60) | 4 |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | восходящий |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
