# Трекер кошелька HL

Следит за **кошельками Hyperliquid** и сообщает обо всём, что они делают:

- **сделки**: открыл, добавил, сократил, закрыл, перевернул позицию, ликвидация, спот;
- **ввод, вывод и переводы**;
- **ордера**: поставил, снял, сработал стоп.

## Как добавить кошелёк

В настройках, по одному в строке: адрес и имя через пробел (имя может быть из нескольких слов):

```
0x5688…bbbb Кит с Binance
```

До 8 кошельков. Сделки одной монеты подряд склеиваются в одно сообщение. Под алертом — кнопка
**«Смотреть на Hyperdash»**.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Кошельки — по одному в строке: адрес и имя | список | пусто |
| Сделки: открыл / добавил / сократил / закрыл / ликвидация | вкл/выкл | вкл |
| Ввод, вывод и переводы | вкл/выкл | вкл |
| Ордера: поставил / снял / сработал стоп | вкл/выкл | вкл |
| Не меньше, $ (0 — всё) | число (от 0 до 1000000000) | 0 |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | звон |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
