# Gate: ритм плотностей

Ловит в стакане **Gate Spot** заявки, которые появляются и исчезают **по таймингу** — алгоритм ставит
и снимает уровень по часам.

## Как работает

- Смотрит стаканы монет Gate, которые торгуются и на фьючерсах Binance/Bybit.
- Связывает появления уровня в одну «линию» по остатку и исполнениям и ищет в ней ритм.
- Таблица — найденные ритмы; алерты в Telegram приходят отдельным, надёжным каналом и не теряются
  при перезапуске сайта.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Включено | вкл/выкл | вкл |
| Фьючерсы и объём | выбор (binance_or_bybit, binance, bybit) | binance_or_bybit |
| Циклов для подтверждения | число (от 5 до 12) | 6 |
| Окно переноса, мс | число (от 100 до 1000) | 500 |
| Мин. объём фьючерсов 24ч, $ | число (от 0 до 1000000000000) | 0 |
| Диапазон от bid/ask, % | число (от 0.01 до 20) | 2 |
| Мин. плотность, $ | число (от 100 до 1000000000) | 3000 |
| Период размещений, секунд | число (от 5 до 300) | 30 |
| Искать период 60 с | вкл/выкл | вкл |
| Допуск времени, ± сек | число (от 0 до 10) | 1 |
| Мин. повтор, % от старта | число (от 1 до 100) | 100 |
| Окно, мин | число (от 2 до 120) | 10 |
| Допуск расстояния, ± п.п. | число (от 0 до 20) | 0.15 |
| Сторона стакана | выбор (both, bid, ask) | both |
| Только монеты | список | пусто |
| Исключить монеты | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка Telegram | число (от 0 до 10000000) | 0 |
| Пуш Bark | вкл/выкл | выкл |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
