# Раг прокидами

Ловит **слив монеты лесенкой**: прокид продажей в рынок, цена встаёт ниже и не возвращается, через
полминуты следующий, и так много раз. Обычный дамп так не выглядит (одна свеча и отскок), обычный слив
тоже (плавное сползание без ступенек).

## Пять примет вместе

1. **Прокиды**: быстрое падение за несколько секунд, почти всё — продажи в рынок, на заметную сумму.
2. **Лесенка**: после вершины прокидов не меньше заданного числа, и падение сделали **именно они**
   (например, 80% падения — прокиды, а не плавное сползание).
3. **Всплеск объёма** на каждом прокиде: в разы выше обычного объёма монеты.
4. **Раг, а не отскок**: цена ниже вершины на заданный процент и почти не отыграла от дна.
5. **Ступеньки, а не один дамп**: ни один прокид не составляет большую часть падения.

Срабатывает **как можно раньше**: условия проверяются каждую секунду. Если раг продолжается и цена ушла
ещё ниже — придёт «раг продолжается».

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Окно рага, мин | число (от 1 до 180) | 15 |
| Падение от вершины, % | число (от 1 до 90) | 4 |
| Мин. прокидов | число (от 2 до 100) | 3 |
| Прокид: падение за 5с, % | число (от 0.1 до 20) | 0.6 |
| Прокид: продали не меньше, $ | число (от 0 до 100000000) | 3000 |
| Прокид: доля продаж, % | число (от 50 до 100) | 65 |
| Прокид: продажи × к обычному объёму за 5с | число (от 0 до 100) | 3 |
| Прокиды — не меньше, % падения | число (от 0 до 100) | 80 |
| Макс. отскок от дна, % от падения | число (от 0 до 100) | 35 |
| Один прокид — не больше, % от всех прокидов | число (от 10 до 100) | 75 |
| Повтор, если упал ещё на, % | число (от 0 до 90) | 10 |
| Кулдаун на пару, мин | число (от 0 до 1440) | 30 |
| Мин. объём 24ч, $ | число (от 0 до 10000000000) | 0 |
| Рынки | рынки | фьючерсы и спот |
| Биржи | биржи | все |
| Котируемые | список | USDT, USDC |
| Чёрный список базовых | список | USDC, FDUSD, TUSD, BUSD, DAI, USDE, USD1, USDP, EURI, XUSD,  |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | низкий |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
