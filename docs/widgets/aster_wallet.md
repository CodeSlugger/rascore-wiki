# Трекер кошелька Aster

Следит за **кошельками Aster**: позиции (открыл, добавил, сократил, закрыл), ордера (поставил, снял),
ввод и вывод.

## Особенности

- Aster не отдаёт сделки веб-торговли, поэтому трекер ловит **изменения позиций** опросом раз в несколько
  секунд. Цена в алерте — примерная, на момент опроса.
- Ввод и вывод определяются по скачку баланса, когда позиции не менялись.
- Кошелёк со включённой приватностью ничего не показывает.

Кошельки — по одному в строке: адрес и имя. До 20 кошельков.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Кошельки — по одному в строке: адрес и имя | список | пусто |
| Позиции: открыл / добавил / сократил / закрыл | вкл/выкл | вкл |
| Ввод и вывод (по изменению баланса) | вкл/выкл | вкл |
| Ордера: поставил / снял | вкл/выкл | вкл |
| Не меньше, $ (0 — всё) | число (от 0 до 1000000000) | 0 |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | звон |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
