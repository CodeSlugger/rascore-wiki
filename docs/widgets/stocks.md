# Фонда - CEX

Сравнивает **цену акции на бирже США** (NYSE, NASDAQ, NYSE Arca) с её **токеном на криптобиржах**.

- Когда рынок США закрыт, сравнение идёт с ценой **после закрытия** (after-hours).
- Если токен есть на одной бирже, справедливая цена («Фейр») — цена акции.
- Если токен на нескольких биржах — показывается и **разница между биржами**, и сравнение с фондой по
  всем биржам сразу.
- В Telegram можно слать только в часы рынка США (и за час до открытия), с учётом праздников.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Спред от, % | число (от 0.05 до 50) | 1 |
| Пороги по тикерам | группы порогов | нет |
| Опрос фонды, сек | число (от 10 до 600) | 30 |
| Кулдаун на связку, сек | число (от 0 до 7200) | 600 |
| Мин. объём 24ч, $ | число (от 0 до 10000000000) | 0 |
| Макс. спред стакана, % | число (от 0 до 50) | 1 |
| Строк в таблице | число (от 5 до 300) | 40 |
| Алерты при закрытом рынке | вкл/выкл | вкл |
| Рынки | рынки | фьючерсы и спот |
| Биржи | биржи | все |
| Только тикеры | список | пусто |
| Котируемые | список | USDT, USDC |
| Чёрный список тикеров | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Telegram только в часы рынка США | вкл/выкл | вкл |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | звон |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
