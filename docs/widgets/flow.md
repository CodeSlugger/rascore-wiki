# Разнолот

Ловит **односторонний поток рыночных ордеров разными лотами**: $1200, $9800, $4800… Одинаковых пар
нет, поэтому «Алгос» такое не видит.

## Три приметы вместе

1. **Поток односторонний**: почти весь объём окна идёт в одну сторону.
2. **Объём аномален для этой монеты**: в разы выше её обычного минутного объёма. Порог считается от
   нормы самой монеты, поэтому $18k на тонком Aster — сигнал, а на Binance — шум.
3. **Цена идёт туда же**, куда бьёт поток.

Плюс несколько **крупных для этой монеты** принтов. Залп в одну секунду считается одним ордером, а не
работой алгоритма. Два одинаковых лота подряд — это «Алгос», и разнолот такое пропускает, чтобы не было
двух алертов на одно событие.

## Алерт

Секундный график с отмеченными принтами.
