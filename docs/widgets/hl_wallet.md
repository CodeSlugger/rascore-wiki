# Трекер кошелька HL

Следит за **кошельками Hyperliquid** и сообщает обо всём, что они делают:

- **сделки**: открыл, добавил, сократил, закрыл, перевернул позицию, ликвидация, спот;
- **ввод, вывод и переводы**;
- **ордера**: поставил, снял, сработал стоп.

## Как добавить кошелёк

В настройках, по одному в строке: адрес и имя через пробел (имя может быть из нескольких слов):

```
0x5688…bbbb Кит с Binance
```

Сделки одной монеты подряд склеиваются в одно сообщение. Под алертом — кнопка **«Смотреть на Hyperdash»**.

К алерту по позиции дописываются **ТВХ** (средняя цена входа) и **цена ликвидации** с расстоянием до неё от
текущей цены, например `ТВХ 0.0739 · ликв 0.0767 (6.5% от цены)`.

Мгновенно, по живому потоку, бот следит за **8 кошельками** — больше Hyperliquid с одного сервера не даёт.
Остальные проверяются **раз в 10 секунд** по позициям: открыл, добавил, сократил, закрыл, ликвидирован
(ликвидацию узнаём по цене у прежней точки ликвидации). Ордера и переводы у таких кошельков не видны.

## До ликвидации

Раз в 10 секунд трекер проверяет позиции **всех** кошельков и предупреждает, когда цена подошла к
ликвидации **ближе 5%, 4%, 3%, 2% и 1%** — по одному алерту на ступеньку:

```
XPL-6: ⚠️ до ликвидации 2.8% (<3%) · LONG XPL 446 770 ($33.0k)
цена 0.0709 · ликв 0.0689 · ТВХ 0.0736
```

Если цена отошла от ликвидации дальше ступеньки на полпроцента, ступенька снова взводится.

## Чёрный список монет

Монеты из чёрного списка (например, `BTC`, `WLFI`) не алертят, даже если кошелёк ими торгует.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Кошельки — по одному в строке: адрес и имя | список | пусто |
| Сделки: открыл / добавил / сократил / закрыл / ликвидация | вкл/выкл | вкл |
| Ввод, вывод и переводы | вкл/выкл | вкл |
| Ордера: поставил / снял / сработал стоп | вкл/выкл | вкл |
| Не меньше, $ (0 — всё) | число (от 0 до 1000000000) | 0 |
| Чёрный список монет — о них не пишем (WLFI, ASTER, BTC) | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | звон |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
