# Поля и виджеты

## Поле

**Поле** — вкладка-дашборд. Их можно завести несколько, например «Скальп», «Ончейн», «TWAP».
Кнопки вверху: создать новое поле, удалить текущее.

## Виджет

**Виджет** — один детектор на поле: «Движения цены», «Плотности», «Алгос» и т. д.

- Нажмите **«+»** и выберите тип — виджет появится на поле со своими настройками по умолчанию.
- Виджеты двигаются и растягиваются мышью. Поле — сетка шириной 64 клетки.
- Можно поставить **несколько виджетов одного типа** с разными порогами: например, один «Алгос» под
  Binance, другой под Aster.
- У каждого виджета свои настройки, своя лента и своя ветка в Telegram.
- Не больше **25 виджетов** на аккаунт.

## Как выглядят виджеты

- **Лента** — алерты строками, новые сверху. Наведите курсор — подробности; клик — график момента
  (у «Движений» клик копирует тикер).
- **Таблица** — живой список: плотности, TWAP, ритмы, арбитраж, фонда, депег, переводы, статус ввода-вывода.

## Поделиться полем

Поле можно выгрузить и отдать другому человеку. Ваши личные настройки (чаты, ветки, ссылки пушей) не
переносятся, а доставка (Telegram, Bark, открытие в терминале) у получателя будет **выключена** — чтобы
чужое поле не начало слать в чужие чаты. Подробнее — [Обмен полями](../tools/share).
