# Alpha: лесенка + разнолот

Ловит **алгос Binance Alpha**: над ценой строится лесенка продаж → идут покупки разнолотом на Alpha и
на фьючерсе Binance → лесенку съедают → алгос выключается.

## Приметы

- **Сборка**: на продаже Alpha выше цены за пару минут появляются новые крупные уровни, цена стоит.
- **Покупки**: на Alpha темп покупок в разы выше фона, на фьючерсе — пачка покупок одного размера в долларах.
- **Выключение**: покупки на Alpha падают ниже четверти темпа.

## «Смотреть»

Отметьте монету кнопкой «Смотреть» — придёт алерт, как только на Alpha над ценой появится первый крупный
сайз (порог настраивается).

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Алерт при включении и выключении алгоса (все монеты) | вкл/выкл | вкл |
| Смотреть монеты: алерт на первый сайз над ценой на Alpha | список | пусто |
| Первый сайз от, $ | число (от 5000 до 1000000000.0) | 10 000 |
| Telegram | вкл/выкл | выкл |
| Ветка Telegram | число (от 0 до 10000000) | 0 |
| Пуш Bark | вкл/выкл | выкл |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
