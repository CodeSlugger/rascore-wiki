# Депег стейблов

Ловит, когда **стейблкоин торгуется мимо привязки**: USDC, FDUSD, DAI против доллара; EURI, EURC против
евро; PAXG, XAUT против унции золота. Смотрит все биржи и оба рынка сразу: депег обычно начинается на
одной площадке.

Курс привязки для евро берётся у Yahoo, для золота — спот унции. Депег самого USDT не виден: на биржах
он котируемая валюта, но проявляется как синхронный уход всех долларовых стейблов в одну сторону.

## Местные валюты

Ещё виджет смотрит **USDT и USDC в местных валютах** — реал (BRL), лира (TRY), песо (ARS, MXN, COP), рэнд,
злотый, гривна, рупия, найра, лей, крона, тенге, рубль, бат, дирхам, евро, фунт и другие — на Binance,
Bybit и OKX. У таких пар своя постоянная премия к официальному курсу (USDT в песо Аргентины дороже курса
на ~7%), поэтому алерт приходит, когда премия **резко ушла от обычной для этой пары** (обычная — среднее
за последние часы). В алерте — и сдвиг, и сама премия к курсу. Отдельную валюту можно убрать в чёрный
список (`ARS`, `NGN`…).

Картинка — минутные свечи с линией привязки.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Отклонение от привязки от, % | число (от 0.01 до 50) | 0.3 |
| Сторона | выбор (below, both, above) | below |
| Спот: только ниже привязки | вкл/выкл | вкл |
| Мин. объём 24ч, $ | число (от 0 до 10000000000) | 100 000 |
| Строк в таблице | число (от 5 до 300) | 40 |
| Кулдаун на связку, сек | число (от 0 до 86400) | 900 |
| Рынки | рынки | фьючерсы и спот |
| Биржи | биржи | все |
| Только стейблы | список | пусто |
| Чёрный список стейблов | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Telegram только в часы рынка США | вкл/выкл | выкл |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | низкий |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
