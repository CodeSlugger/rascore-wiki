# Спред-боты

Ловит на **Gate (спот)** алгоритм, который **ставит крупную заявку на покупку внутрь спреда, а в неё
наливают рыночными продажами**.

## Условия (все сразу, за 10 секунд)

1. Заявка на покупку **от $3 000** зашла внутрь спреда.
2. В неё **продали рынком от $5 000**.
3. **CVD** монеты упал сильнее чем на **30% оборота**: продают рынком.

Если в заявку не наливают — это обычный маркетмейкер, и алерта нет. Все три порога настраиваются.

## Настройки

| Настройка | Что задаёт | По умолчанию |
|---|---|---|
| Рынки Gate | рынки | спот |
| Заявка в спред от, $ | число (от 100 до 10000000) | 3000 |
| Налили в неё шортами за 10 с от, $ | число (от 100 до 100000000) | 5000 |
| CVD за 10 с падает сильнее, % оборота | число (от 1 до 100) | 30 |
| Держится не меньше, сек | число (от 10 до 600) | 10 |
| Выключился — нет налива, сек | число (от 10 до 3600) | 60 |
| Алерт, когда налив кончился | вкл/выкл | выкл |
| Кулдаун на монету, мин | число (от 0 до 1440) | 30 |
| Строк в таблице | число (от 5 до 300) | 50 |
| Только монеты | список | пусто |
| Чёрный список | список | пусто |
| Telegram | вкл/выкл | выкл |
| Ветка | число (от 0 до 10000000) | 0 |
| Открывать в терминале | вкл/выкл | выкл |
| Пуш Bark | вкл/выкл | выкл |
| Звук алерта | выбор | бип |

Ещё у виджета есть общие настройки доставки — см. [Настройки виджета](../start/settings).
